## Identidad del tema

Paleta de alto contraste: fondo negro, texto blanco,
velas monocromáticas y acentos verde lima. El rojo se reserva para
señales de venta, precios Ask y niveles de riesgo.

**Estilo:** oscuro, minimalista, alto contraste\
**Uso recomendado:** gráficos de velas, análisis técnico y objetos
personalizados.

## 4. Reglas para mantener la coherencia visual

1.  **Verde lima** (`#00FF00`): reservarlo para el precio, señales
    alcistas y niveles de soporte importantes.
2.  **Rojo** (`#FF0000`): reservarlo para Ask, señales bajistas y
    riesgo.
3.  **Cian y azul**: utilizarlos para indicadores técnicos, evitando que
    compitan visualmente con las velas.
4.  **Amarillo y naranja**: utilizarlos con moderación para alertas,
    entradas y niveles relevantes.
5.  **Violeta y magenta**: asignarlos a indicadores secundarios u
    osciladores.
6.  **Grises**: utilizarlos para cuadrículas, zonas auxiliares y
    anotaciones discretas.
